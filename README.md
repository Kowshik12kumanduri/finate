# FinSight AI – Predictive Financial Health & Risk Advisor 🚀

FinSight AI is a next-generation predictive personal finance and autonomous risk management platform designed for modern professionals. Built with React 18, TypeScript, Tailwind CSS, Recharts, and Vite, FinSight delivers institutional-grade behavioral analytics, multivariate financial health diagnostics, and proactive fraud surveillance.

---

## 🌟 Key Features & Rectifications in FinSight AI 2.0

### 1. 100% Client-Side LocalStorage Persistence
- All transactions, custom category budgets, accounts, recurring bills, and chat histories automatically persist across browser refreshes.
- 1-Click JSON Backup Export & Import and Instant Demo Data Reset to restore pristine evaluation states.

### 2. Dual AI Copilot Architecture (Live LLM + Deterministic Neural Heuristics)
- Live LLM Integration: Connect Google Gemini 1.5/2.0 or OpenAI GPT-4o-mini API keys directly in Settings for conversational reasoning over your actual accounts, burn rates, and pending alerts.
- Resilient Offline Fallback: Deterministic financial intelligence engine provides expert analysis on DTI ratios, tax deductions, emergency runway, and spending cuts without requiring an API key.
- Voice Read-Aloud (TTS): Integrated Web Speech API for audible financial briefings.

### 3. What-If Scenario Simulator & 1,000-Run Monte Carlo Stress Testing
- Interactive stress-testing sliders for Salary Fluctuations, Job Loss (0 income for 1-12 months), Inflation Spikes (+0-15%), New Loan EMIs, and Capital Shocks (e.g. Medical Emergencies).
- Executes 1,000 randomized stochastic simulations across 12 months, calculating survival rates, bankruptcy risk percentages, and minimum liquid runway.

### 4. Interactive Goal Planner & FIRE (Financial Independence) Calculator
- Track progress toward custom goals (Emergency Buffers, Real Estate Down Payments, Travel, Wealth Building).
- Integrated FIRE Calculator based on the 4% Safe Withdrawal Rule (SWR), computing Lean FIRE, Standard FIRE, and Fat FIRE milestone corpuses.

### 5. Indian Union Budget Income Tax Optimizer (FY 2025-26 & 2026-27)
- Automated side-by-side comparison of Old Tax Regime vs New Tax Regime.
- Incorporates enhanced standard deduction (₹75,000 under New Regime vs ₹50,000 under Old Regime), Section 87A rebates, Section 80C, 80D, and HRA exemptions.

### 6. Loan Principal Prepayment & Amortization Optimizer
- Dynamic loan payoff simulator for active credit and personal loans.
- Shows real-time interest savings and tenure reduction when paying extra toward principal.

### 7. AI Anomaly Surveillance & Automated Bank Dispute Letter Generator
- Flagged suspicious transactions (e.g. off-hours high-value retail debits) feature deep behavioral forensic diagnostics.
- 1-Click Formal Bank Dispute & Chargeback Request Letter Generator formatted for RBI compliance, NPCI, and bank grievance cells.

### 8. Dynamic Rolling Cash Flow Trajectory
- Dynamic 30-day forecast engine projecting daily liquidity from active recurring mandates and variable spending burn rates with confidence intervals.

### 9. Multi-Currency Converter
- Live currency switcher supporting INR (₹), USD ($), EUR (€), GBP (£), AED (AED), and SGD (S$).

### 10. Executive Printable Audit Dossier (PDF-Ready)
- Print-optimized executive financial health memorandum with scoring formulas, pillar metrics, and verification certification.

## 🚀 Getting Started Locally

```bash
# 1. Install dependencies
npm install

# 2. Start the local development server
npm run dev

# 3. Build for production
npm run build

# 4. Preview the production build
npm run preview
```

The app runs at: http://localhost:5173
